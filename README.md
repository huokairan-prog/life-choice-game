# 人生选择

一款中文网页人生模拟游戏。创建角色后，玩家会在篮球、工作、旅行、关系、家庭和创业等事件中作出选择；每个选择都会改变属性、关系、职业、资产和结局。

这是一个通用示例版本：默认角色、城市与剧情设定均为虚构内容，不包含原作者的个人资料、存档、支付凭据或数据库。

## 功能

- 九步角色创建：外貌、身体、性格、家庭、天赋、兴趣、目标与难度都会影响后续事件。
- 三幕开场主线“北城机会”：早期选择会改变试训过程、序章结局，并在六个月后触发对应回响。
- 月度人生事件与多结局系统。
- 篮球球场、深夜来电、家庭晚餐、夜间事业与旅途出发等场景插画。
- 本地存档、档案、关系、资产、成就与成长页。
- 可选 Python 后端：服务端权威的成长币、属性提升、初始现金档位与模拟支付接口。

## 本地运行

游戏的纯剧情部分可以直接打开 `index.html`。如需完整使用成长功能、存档服务与本地接口，请启动后端：

```bash
python3 -m pip install -r backend/requirements.txt
python3 -m backend.app
```

然后在浏览器访问 `http://127.0.0.1:8787`。

### 在手机上预览

复制环境示例文件并保持 `LIFE_HOST=0.0.0.0`：

```bash
cp backend/.env.example backend/.env
python3 -m backend.app
```

让电脑和手机连接到同一可信 Wi‑Fi；启动日志会给出类似 `http://192.168.x.x:8787` 的地址，在手机浏览器打开即可。不要在公共网络开放此开发服务器。

## 安全与支付说明

- `backend/.env`、`backend/data/`、证书和真实密钥均已被忽略，不应提交。
- 开发模式的支付完成接口仅用于本地演示；生产环境会关闭它。
- 微信内真实支付使用 JSAPI：先通过公众号网页授权获得 OpenID，再由后端创建预支付订单并调用微信回调验签、查单确认到账。将后端部署到公网 HTTPS 后，在 `backend/.env` 中填写商户号、支付证书、APIv3 密钥、网页授权密钥与回调地址；前端 `js/runtime-config.js` 只填写 API 域名，绝不能放任何密钥。
- GitHub Pages 仅托管剧情网页，不能接收支付回调。若接入真实登录、支付或未成年人服务，请完成安全审计、隐私合规、退款与风控流程后再上线。
